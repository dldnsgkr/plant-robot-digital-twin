# Module 3 (Gas/Safety) 구현 상태

## 완성·검증된 것

### 1. 가스 확산 시뮬레이션 (`gas_simulation/gas_field.py`)
- 가우시안 플룸 모델: 풍하 거리 비례 퍼짐(σ=0.8+0.35d), 1/(U·σ) 희석,
  풍상 등방 확산, 시변 돌풍(±20%) + 센서 노이즈
- 오프라인 검증: 플룸 중심선 따라 단조 증가(16→56ppm), 최대점은 소스
  풍하 2.4m — 실제 플룸의 특성 재현
- 토픽: 로봇 위치 농도(5Hz), 농도장 그리드(관제용), 풍향계, truth

### 2. Source Seeking (`source_seeking/source_seeker.py`)
- 4-모드 상태기계: CAST(확장 나선) / CLIMB(최소제곱 구배 상승) /
  SURGE(풍상 전진+횡풍 센터링, 히스테리시스 8s) / RETURN(최고농도 백트래킹)
- LiDAR 반발 조향 장애물 회피, 발견 판정(40ppm 2s), /gas/alarm 게이트
  (통합 시나리오에서 미션이 알람을 발령해야 탐색 시작)

### 3. 자율 복귀 (`return_to_home/rth.py`)
- 배터리 모델(이동/대기 차등 소모) + 20% 트리거, 통신 음영 진입 트리거
- A* 경로계획(0.25m 격자, 0.4m 팽창): 4개 시작점 전부 성공(최장 49.9m)
- **통합 데모 검증**: 공장 이동 중 배터리 20% 도달 → 자동 발동(미션 제어권
  양보) → 19-waypoint 경로 주행 → 충전소 도킹 완료(오차 0.50m) → 재충전

## 이력: '기생 결합' 진단의 전말 (REPORT 문제해결 사례)

한동안 이 모듈의 폐루프 주행(탐색 수렴·복귀 추종)이 방향 의존적으로
표류했고, 격리 실험으로 '측방→후진, 후진→스핀' 기생 결합을 정량화해
축 정렬 주행 등 우회를 설계했다. 그러나 **진짜 원인은 게이트 노드의
타이머 중첩 버그**(디버그 타이머 추가 시 __init__ 잔여 코드가 메서드로
흡수 → 2초마다 100Hz 제어 타이머 복제, 실측 44개 누적)였다.

수정 후 전 방향 이동·회전이 정상화되었고(전진 0.17m/s 직진, 순수 측방,
후진 스핀 없음, 회전 0.185rad/s 추종), 우회 주행을 정상 헤딩 조향으로
환원해 통합 시나리오(게이지 점검→공장 이동→자율 복귀 도킹)가 완주됐다.

교훈: 시간 경과에 따라 열화하는 제어 이상은 제어 이론이 아니라
**실행 기반(타이머·스레드·큐)의 누적 결함**을 먼저 의심할 것.
