# Module 3 (Gas/Safety) 구현 상태

## 완성·검증된 것

### 1. 가스 확산 시뮬레이션 (`gas_simulation/gas_field.py`)
- 가우시안 플룸 모델: 풍하 거리 비례 퍼짐(σ=0.8+0.35d), 1/(U·σ) 희석,
  풍상 등방 확산, 시변 돌풍(±20%) + 센서 노이즈
- 오프라인 검증: 플룸 중심선 따라 단조 증가(16→56ppm), 최대점은 소스
  풍하 2.4m — 실제 플룸의 특성 재현
- 토픽: 로봇 위치 농도(5Hz), 농도장 그리드(관제용), 풍향계, truth

### 2. Source Seeking (`source_seeking/source_seeker.py`)
- 4-모드 상태기계: CAST(원형 탐색) / CLIMB(최소제곱 구배 상승) /
  SURGE(풍상 전진+횡풍 센터링, 히스테리시스 8s) / RETURN(최고농도 백트래킹)
- LiDAR 반발 조향 장애물 회피, 발견 판정(40ppm 2s) 및 위치 보고
- 검증: 농도 12→40ppm 상승 추세, 소스 3.9m 접근 기록. 단 최종 수렴은
  아래 '기반 제약'으로 300s 내 불안정

### 3. 자율 복귀 (`return_to_home/rth.py`)
- 배터리 모델(이동 0.25%/s) + 20% 트리거 ✓ 라이브 검증
- 통신 음영(복도 x>48, 5s 체류) 트리거
- A* 경로계획(0.25m 격자, 0.4m 팽창): 공장·복도·출입구·장애물 우회
  4개 시작점 전부 성공 (최장 49.9m)
- 도킹 판정 + 충전 모델. 경로 추종은 축 정렬 게걸음 — y축 수렴 확인,
  x축은 아래 제약으로 표류

## 기반 제약 (stage1 게이트) — 체계적 실험으로 규명

격리 실험 시리즈로 자작 게이트의 속도 추종 한계를 정량화:

| 명령 | 실측 결과 |
|---|---|
| 전진 vx=0.2 | 정상 (0.13m/s, 직진) |
| 측방 vy=0.15 | +y 이동하나 기생 후진 −0.10m/s |
| 회전 wz±0.15 | 회전은 되나 전진 붕괴·기생 병진, 좌우 비대칭 |
| 후진 vx=−0.15 | 이동 중 기생 회전 → 20s에 요 −2.7rad (스핀) |

- 오도메트리 속도 PI 폐루프 추가로 측방 기생 후진 1/3로 개선
- 그러나 지속 측방·후진에서 기생 요 토크가 요 홀드와 상호작용해
  누적 시 180° 플립 발생 → 장거리 폐루프 주행(seeker 수렴, RTH x축)이 표류

**결론**: Module 3 알고리즘이 아니라 저수준 보행의 속도 충실도가 병목.
해결 경로(차기 작업): ① 검증된 4족 컨트롤러로 교체(CHAMP Jazzy 포팅 등)
② stage3 토크 기반 Convex MPC + WBC ③ Nav2 통합 시 회전 없는 경로 제약.
이 규명 과정(가설→격리실험→정량화)은 REPORT.md의 핵심 문제해결 사례.
